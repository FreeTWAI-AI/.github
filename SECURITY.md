# Security reporting

Maintainer: [teddashh](https://github.com/teddashh).

Use an existing private contact channel with the maintainer for a vulnerability,
credential exposure or private data issue. If you do not have one, open an issue
asking for a private reporting channel without exploit details or sensitive
data. No dedicated security mailbox, response-time guarantee or bounty program
is established by this bootstrap.

Include the affected repository, exact commit, impact and a sanitized
reproduction. Never post a live secret in a public issue or pull request.

Current templates are internal-preview building blocks. They do not provide
production authorization, official-status signatures, provider credential
custody or payment processing.
